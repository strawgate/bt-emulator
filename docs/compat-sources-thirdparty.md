# Third-party (non-`braintrustdata`) Braintrust API compatibility corpus

Researched 2026-11-16 across public GitHub. Nothing in these repos was executed.

**Source policy.** Only public, permissively licensed sources (MIT/Apache/BSD) may be vendored or run. Entries marked as having no license, or a copyleft or non-commercial license, are reference only and are not copied.
The Braintrust interaction counts are static: they count recorded interactions, mock routes or stubs found in the code. Nothing was replayed.

## TL;DR

- **Third-party recorded HTTP traffic to Braintrust is almost nonexistent.** There are no HAR files and no public third-party VCR cassettes. `delightful-ai/leaven` holds an unlicensed mirror of `braintrust-sdk-python` cassettes; use the originals instead.
- **The most valuable find is `PreMan-Inc/MindTrust` ("Verus").** It is an Apache-2.0, independently written, self-hosted Braintrust-compatible server, which makes it the closest analogue to bt-emulator. It has about 32 routes and contract tests that run the unmodified `braintrust@3.37.2` (JS) and `braintrust==0.45.0` (Python) SDKs over real HTTP.
- **Hand-written mocks are plentiful.** Several are permissively licensed, encode request and response shapes, and are worth porting as test cases: `mongodb/agents`, `riddler/braintrust`, PostHog, onyx, latitude, `fvoges/terraform-provider` (MPL-2.0), laravel, everruns, chalk and Grace (OTLP).
- **Major frameworks have no Braintrust HTTP tests.** This covers langchain, llama_index, pydantic-ai, dspy, haystack, openai-agents, vercel/ai, inspect_ai, agno, adk, strands, autogen, livekit and pipecat. Their Braintrust integrations live in `braintrustdata` repos, and crewAI has docs only. LiteLLM is the exception: it ships a built-in `BRAINTRUST_MOCK` mode, but it has little wire fidelity.
- **Search coverage had gaps.** I ran about 30 `gh search code` and repo queries. GitHub code search caps each query at 100 results and allows 10 queries a minute. grep.app was blocked by a Vercel bot check (HTTP 429). Sourcegraph's public stream API returned 0 matches for every query.

## Endpoint coverage across permissively licensed third-party sources

- **SDK data plane** (`/api/apikey/login`, `/api/project/register`, `/api/experiment/register`, `/logs3`, `/experiment-comparison2`, `/version`, `/api/base_experiment/get_id`): MindTrust, mongodb/agents, and the platform cassette (reference only).
- **REST v1 inserts and fetches** (`/v1/{project_logs,experiment,dataset}/{id}/{insert,fetch,feedback,summarize}`): riddler, PostHog, laravel, everruns, betterlite, zep, opik-to-bt, cursor-hook.
- **Control-plane CRUD** (`/v1/{project,role,group,api_key,view,project_tag,project_score,ai_secret,env_var,organization,function,prompt,user}`): fvoges (MPL-2.0), riddler, opik-to-bt.
- **`/btql`**: latitude, onyx, promptfoo, plus the nemo-compass real bodies, which are derived from upstream.
- **`/otel/v1/traces`**: Grace (a real SDK capture), chalk, and agent-otel (the `x-bt-parent` gotcha).

## Categories that came up empty

- **HAR files**: none (`gh search code braintrust --extension har` returned 0).
- **Third-party VCR, polly, nock or msw recordings of real Braintrust traffic**: none in public repos.
- **Framework integration tests (category 2)**: none that hit the HTTP API, apart from LiteLLM's low-fidelity mock.
- **Issue and discussion payloads (category 4)**: skipped as low priority.
